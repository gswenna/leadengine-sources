# leadengine-sources · 云端源清单

海外获客引擎(EmailFinder)用的**公开目录源清单**。工具每次「一键全自动抓取」都会自动拉取本文件，
作为"去哪里批量找到目标公司"的来源（0 token / 0 成本）。更新本文件 = 所有买家自动用上新源。

> 本仓库只存**公开的目录/榜单/黄页/协会会员 URL**。禁止上传任何名单、个人数据、密钥。

## 文件格式（source_library.json）

```json
{
  "国家|行业": ["https://目录页1", "https://榜单页2", "..."],
  "USA|fashion": ["https://..."],
  "Senegal|auto": ["https://..."]
}
```
